پروژه اندروید بازی سرمایه‌دار

ساخت APK:
1. پوشه پروژه را در یک مخزن GitHub قرار دهید.
2. به Actions بروید.
3. گردش‌کار Build Android APK را با Run workflow اجرا کنید.
4. پس از موفقیت، فایل sarmayedar-debug-apk را از بخش Artifacts دانلود کنید.
5. ZIP خروجی را باز کنید و app-debug.apk را روی گوشی اندروید نصب کنید.

این نسخه Debug است و برای نصب آزمایشی مناسب است. برای انتشار در فروشگاه، APK/AAB باید با کلید امضای اختصاصی امضا شود.
